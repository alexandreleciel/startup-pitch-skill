# Upstream sources

This file is the public inventory of the creators, repositories, articles and data sources that informed the `startup-pitch` skill, so that the maintainer can contact each creator. Compiled 2026-11-10 from the research notes in `research/` and the per-file attribution notes in `research/attribution/`.
Every component listed here was studied and re-synthesised in our own words and structure, and nothing is copied verbatim; named concepts (fundraising vertebrae, Email Test, Power Grid, magic question) are credited in-line in the reference files that use them.
Repository rows give the GitHub URL, the short commit hash of the clone that was read, the owner as shown on GitHub, and whether a license file is present in that clone (file name and first line, recorded as a fact, no analysis).
Contact and permissions are handled by the maintainer; this file records facts only. The repository itself is released under the MIT License.
